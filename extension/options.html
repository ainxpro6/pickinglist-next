Picking List Desty

Tentukan alamat web Picking List App Anda di bawah ini agar file PDF Desty Omni otomatis diproses saat Anda mengklik ikon ekstensi.

Default: http://localhost:3000. Jika sudah dideploy di Vercel, ganti dengan URL Vercel Anda (misalnya: https://pickinglist-next.vercel.app).

Cara Penggunaan

  • Buka halaman PDF Picking List di Desty Omni (link diawali dengan https://desty-upload-indonesia).
  • Klik ikon ekstensi ini pada browser Anda.
  • Tab baru akan otomatis terbuka di sebelah kanan tab Anda saat ini, langsung mengunduh dan menyajikan tabel print preview!
